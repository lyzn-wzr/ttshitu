# 自定义算法接入示例（仅测试环境）

此目录仅演示调用方如何通过 SDK 的通用接口注册自己的算法，供本地验收使用。
SDK 不内置或导出这个模板算法，调用方安装 SDK 后也不会获得它的模板和图片处理依赖。

运行 `pnpm dev`，打开 [模板识别模式](http://127.0.0.1:3210/?mode=template)。
可以载入 `0−7` 示例或上传同样式图片，点击“开始本地识别”，查看算式、答案、最低相似度、类别分差和算法耗时。

识别器通过 SDK 的 `algorithms` 注册专属类型 `template-math`，名称为“本地算术模板识别”，仅需传入 `typeid: "template-math"`，共用正常识别与记录流程。
拒识返回 `TEMPLATE_REJECTED`，不会调用外部平台。记录位于 `.zk-captcha/acceptance/template/history.sqlite`，成功识别默认价格为零。

`recognizer.ts` 复用“调研 Bun 验证码识别方案”的识别实现；唯一运行时适配是对新建排序数组使用 `sort`，以兼容项目的 ES2022 类型配置。
`model.json` 固定保存原建模集 40 张人工标注图片生成的 120 个字符模板，原阈值为相似度 `0.90`、类别分差 `0.02`，未加入留出图片或重新调参。
原数据集指纹为 `1670046242e1b39d41bfc845effb3308efae03ffb60ead39c4ccf3b1421b05cd`。
示例来自留出集，不参与模板生成；运行时不读取来源项目、历史数据库或调研报告。

仅适配原样式的 130×48 彩色粗体单数字加减乘算术图。相似度不是正确概率，其他字体与版式需要重新标注、校准。
`sharp` 仅为验收开发依赖；算法、模板和示例均不进入 SDK 发布包。
